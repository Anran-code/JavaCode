图书管理系统设计文档：

图书馆系统设计总要求：
设计一个为管理员（admin）和普通用户（user）共同使用的系统：
1.作为管理员，能整体查看图书（book）情况，用户（member）情况，借书（rent）情况，能手动操作完成借书、还书的修改，手动完成充值，图书量的变化和用户余额的变化是自动的
2.作为普通用户，也能查看整体查看图书（book）情况，除此之外，只能看到自己的用户信息和借书情况，并完成借书、还书、充值等行为
3.对于普通用户，设计两种：
    1）一般用户（normalUser）：每次借书为 1 元，借书上限为 5 本，办卡服务为 20 元 / 月 ，之后借书在月内无需缴费，办卡缴费从余额里面扣
    2）普通会员（vipUser）：每次借书为 0.8 元，借书上限为 10 本，办卡服务为 15 元 / 月 ，之后借书在月内无需缴费，办卡缴费从余额里面扣
    成为普通会员需要缴费 50 元（永久）
    借书卡状态由手动维护，系统不自动计算到期日或月费。
    3）设计方案：
    父类：member，包含字段
    a.用户名        String name
    b.用户id        String id
    c.用户余额      double balance
    d.是否办卡      boolean hasCard
    e.当前借书本数   int currentRentNum
    子类：normalUser、vipUser，增加常量字段：（以normalUser为例子）
    private static final double rentPrice = 1.0
    private static final int cardPrice = 20
4.对于图书：设计如下字段
    1）图书名           String name
    2）图书ISBN号       String ISBN
    3）图书总量          int count
    4）图书可借量        int available
5.对于借书情况：map<String,String> rentList ，建立从用户id到图书ISBN的映射
6.对于ui设计：
    1）LoginFrame 登陆界面，从这里决定是谁登录，进入谁的系统界面
    2）AdminLibrarySystemFrame 管理员系统界面，有三页：整体查看图书（book）情况，用户（member）情况，借书（rent）情况
    3）UserLibrarySystemFrame 用户系统界面，只有两页：整体查看图书（book）情况，自己的信息和借书情况

详细项目实现步骤：（ui部分主要是ai辅助）
1.构建需要的数据结构：
LoginUser父类 -> Admin/User子类
登录：这里面系统里会先放好又是User，又是Member的数据，确保上下一致
注册：从User里面拿字段，创建NormalUser
Member父类 -> NormalUser/VipUser子类
2.实现登陆界面
3.实现UserLibrarySystemFrame
    第一页显示图书（book）情况，中间是一个大表格，展示book的几个字段，上方有一个搜索框，可以搜索书本
    右键还有存量的书，有一个小菜单出现在鼠标位置，显示“借书”两个字，点击借书就可以借书，如果到了借书上限就弹窗提示，余额不足也是
    右键没有存量的书，也有小菜单，但是借书两个字是灰色的，也不可以点（点了没反应）
    第二页显示个人信息，上半部分展示member各个字段的信息，下半部分用表格展示借书的情况
    在余额旁边加一个充值按钮，点了出现弹窗，填写充值金额
    右键借书项，也是有小菜单显示还书，点击还书就还了
4.实现AdminLibrarySystemFrame
    第一页ui布局同上
    右键还有存量的书，有一个小菜单出现在鼠标位置，有2项目：借书、查看被借情况
    点击借书：弹出一个窗口，填写借书人id，根据具体情况实现扣款等业务逻辑
    点击查看被借情况：弹出一个窗口，表格显示这本书被哪些人借了（展示这些member的全部字段），右键点击这些人出现还书按钮，点了还书
    第二页显示用户情况，展示所有用户，上面有一个搜索框可以搜索用户
    右键点击用户，有一个小菜单显示查看借书情况、充值，弹窗用表格展示被借的所有书，右键点击这些书同理也是小菜单还书，点了还书
    充值弹窗可以填写要充值的金额
    第三页显示全部借书情况，展示借书人id，名字，借的书的名字，IBSN，右键点击这些项目同理小菜单还书，点了还书
