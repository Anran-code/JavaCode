# 基础笔记

## 1.项目结构：

1.模块（module） -> 包（package） -> 类（class）

2.一定要有一个入口函数main()

```java
public class HelloWorld{
    public static void main(String[] args){
        System.out.println("HelloWold")
    }
}

1.其中 static 是静态方法，随着类一起初始化，不需要创建实例就可以调用
2.String[] args 指可以接受字符串类型的参数，放在 args[] 里面
    如 java HelloWorld abc def:
    args[0] = abc  args[1] = def
```

## 2.方法的创建:

```java
public static add(int a,int b){
    return a + b;
}
```

调用时可以直接 `add(1,2)` ，因为是静态方法

```java
public add(int a,int b){
    return a + b;
}
```

调用时先初始化：

```java
HelloWorld Add = new HelloWorld();
Add.add(1,1);
```

## 3.强制类型转换：

1.基本数据类型的强制转换：

将取值范围大的数据类型转换为取值范围小的数据类型时，需要使用 `(目标类型)` 进行强制类型转换。

```java
double num = 3.14;
int result = (int) num;
System.out.println(result); // 3，小数部分会丢失
```

`char` 类型也可以强制转换为 `int` 类型，得到该字符对应的 Unicode 编码值：

```java
char letter = 'A';
int code = (int) letter;
System.out.println(code); // 65
```

注意：强制类型转换可能造成数据丢失或数值溢出。

2.引用类型的强制转换：

子类对象可以直接赋值给父类引用，称为向上转型，不需要强制类型转换。

```java
Animal animal = new Dog();
```

将父类引用转换为子类引用，称为向下转型，需要使用 `(子类类型)`：

```java
Dog dog = (Dog) animal;
```

如果父类引用实际指向的对象不是该子类，强制转换时会抛出 `ClassCastException` 异常。因此向下转型前可以使用 `instanceof` 进行判断。

3.`instanceof` 条件判断：

`instanceof` 是运算符，不是方法。它用于判断一个引用指向的对象是否属于指定类型，或者是否属于该类型的子类。

```java
if (animal instanceof Dog) {
    Dog dog = (Dog) animal;
    dog.bark();
}
```

使用 `instanceof` 需要满足以下条件：

1.左边必须是引用类型的变量或 `null`，不能是 `int`、`char` 等基本数据类型。
2.右边必须是类、接口或数组类型，不能是一个对象。
3.左右两边的类型必须存在转换的可能，否则编译器会直接报错。
4.当左边为 `null` 时，判断结果永远是 `false`，不会抛出异常。

```java
Animal animal = null;
System.out.println(animal instanceof Dog); // false
```

JDK 16 及以上版本还可以使用模式匹配，判断成功后直接得到转换后的变量：

```java
if (animal instanceof Dog dog) {
    dog.bark();
}
```

## 4.基本数据类型的分类：

Java 一共有 8 种基本数据类型。

1.整型：

```java
byte a = 1;     // 8位
short b = 2;    // 16位
int c = 3;      // 32位，最常用
long d = 4L;    // 64位，数值后通常加 L
```

2.浮点型：

```java
float a = 3.14F;  // 32位，数值后必须加 F
double b = 3.14;  // 64位，Java 中的小数默认是 double
```

浮点数存在精度误差，不能直接用于要求精确的金额计算。

3.字符型：

```java
char letter = 'A'; // 16位，使用单引号
```

`char` 用于表示一个 UTF-16 代码单元，可以和 `int` 相互转换。

4.布尔型：

```java
boolean flag = true;
boolean result = false;
```

`boolean` 只有 `true` 和 `false` 两个值，不能像 C++ 一样使用 `0` 和 `1` 代替。

5.字符串：

```java
String name = "Java"; // 使用双引号
```

`String` 不是基本数据类型，而是引用类型。字符串对象创建后内容不可改变。

## 5.随机数字验证码和 Math 类：

1.`randomKeyNumber` 方法：

```java
public static String randomKeyNumber(int len){
    String key = "";
    for(int i = 0;i < len;i++){
        int num = (int)(Math.random() * 10);
        key += num;
    }
    return key;
}
```

该方法用于生成长度为 `len` 的随机数字字符串。

1.`key` 用于保存最终生成的验证码。

2.循环执行 `len` 次，每次生成一位随机数字。

3.`Math.random()` 生成 `[0.0, 1.0)` 范围内的 `double` 类型随机数。

4.乘以 `10` 后范围是 `[0.0, 10.0)`，强制转换为 `int` 后得到 `0~9`。

5.将每次得到的数字拼接到 `key` 中，最后返回字符串。

返回类型使用 `String`，可以保留验证码开头的 `0`。`Math.random()` 适合普通练习，不适合生成真实项目中的安全验证码。

2.`Math` 类：

`Math` 类位于 `java.lang` 包中，不需要手动导包。它的方法大部分是静态方法，可以直接通过 `Math.方法名()` 调用。

```java
Math.abs(-10);       // 绝对值：10
Math.max(10, 20);    // 最大值：20
Math.min(10, 20);    // 最小值：10
Math.pow(2, 3);      // 幂运算：2的3次方，结果为 8.0
Math.sqrt(16);       // 平方根：4.0
```

3.取整方法：

```java
Math.ceil(3.2);      // 向上取整：4.0
Math.floor(3.8);     // 向下取整：3.0
Math.round(3.5);     // 四舍五入：4
```

注意：`ceil()` 和 `floor()` 返回 `double`，`round()` 根据参数类型返回 `int` 或 `long`。

4.随机数：

```java
double num = Math.random();             // [0.0, 1.0)
int number = (int)(Math.random() * 10); // [0, 9]
```

生成 `[min, max]` 范围内的随机整数：

```java
int number = (int)(Math.random() * (max - min + 1)) + min;
```

5.常用常量和三角函数：

```java
Math.PI;           // 圆周率
Math.E;            // 自然常数
Math.sin(angle);   // 正弦，angle 使用弧度
Math.cos(angle);   // 余弦，angle 使用弧度
Math.toRadians(90);// 将角度转换为弧度
```

## 6.main 方法与类、包、模块：

1.一个包中可以有多个 `main()`：

`main()` 属于类，不属于包。一个包中可以有多个包含 `main()` 的类，但每次运行时只能选择其中一个作为程序入口。

```java
class TestA {
    public static void main(String[] args) {
        System.out.println("运行 TestA");
    }
}

class TestB {
    public static void main(String[] args) {
        System.out.println("运行 TestB");
    }
}
```

在 IDEA 中，点击某个 `main()` 左侧的绿色三角，就会运行这个 `main()`。点击右上角的运行按钮时，会运行下拉框中当前选中的运行配置。

2.一个 `main()` 可以使用多个类：

程序只需要一个入口，但入口中可以创建和调用多个类。

```java
public class Main {
    public static void main(String[] args) {
        Calculator calculator = new Calculator();
        Dog dog = new Dog();

        System.out.println(calculator.add(1, 2));
        dog.bark();
    }
}
```

3.同一个包中的类：

同一个包中的类不需要 `import`，可以直接使用类名。

```java
package com.ranan.basic;

public class Main {
    public static void main(String[] args) {
        Calculator calculator = new Calculator();
        System.out.println(calculator.add(1, 2));
    }
}
```

```java
package com.ranan.basic;

public class Calculator {
    public int add(int a, int b) {
        return a + b;
    }
}
```

注意：`private` 成员仍然只能在定义它的类内部使用。

4.同一模块中的不同包：

不同包之间通常需要使用 `import` 导入目标类，并且目标类和需要调用的方法必须可以被访问。

```java
package com.ranan.app;

import com.ranan.basic.Calculator;

public class Main {
    public static void main(String[] args) {
        Calculator calculator = new Calculator();
        System.out.println(calculator.add(1, 2));
    }
}
```

也可以不使用 `import`，直接写类的完整名称：

```java
com.ranan.basic.Calculator calculator =
        new com.ranan.basic.Calculator();
```

5.不同模块中的类：

不同模块之间调用时，需要同时满足以下条件：

1.调用方模块已经添加对目标模块的依赖。
2.使用 `import` 导入目标类。
3.目标类和需要调用的方法可以被访问。

在 IDEA 中添加模块依赖：

```text
File -> Project Structure -> Modules
     -> 选择调用方模块 -> Dependencies -> 添加目标模块
```

`module-info.java` 是 Java 9 引入的模块描述文件，用于声明模块名称、依赖的模块和对外开放的包。它由开发者创建，放在模块的 `src` 根目录中，与 `com` 等包目录同级：

```text
src
├─ module-info.java
└─ com
   └─ ranan
```

注意：IDEA 中的项目模块和 Java 的模块系统不是完全相同的概念。当前基础练习暂时不需要创建 `module-info.java`，先使用 `package` 和 `import` 即可。

如果项目使用了 `module-info.java`，提供类的模块需要导出包：

```java
module calculator.module {
    exports com.ranan.basic;
}
```

使用类的模块需要声明依赖：

```java
module app.module {
    requires calculator.module;
}
```

6.静态方法和实例方法的调用：

静态方法属于类，可以直接通过类名调用：

```java
int max = Math.max(1, 2);
```

实例方法属于对象，需要先创建对象再调用：

```java
Calculator calculator = new Calculator();
calculator.add(1, 2);
```

简单总结：

| 类的位置      | 是否需要 import | 是否需要添加模块依赖 |
| --------- | ----------- | ---------- |
| 同一模块、同一个包 | 不需要         | 不需要        |
| 同一模块、不同包  | 需要          | 不需要        |
| 不同模块      | 需要          | 需要         |

## 7.方法重载（Overload）：

方法重载是指在同一个类中定义多个同名方法，编译器根据传入的参数选择调用哪一个方法。

```java
public static void printVariable(int num) {
    System.out.println(num);
}

public static void printVariable(String str) {
    System.out.println(str);
}
```

```java
printVariable(12);      // 调用 int 版本
printVariable("qwe");   // 调用 String 版本
```

1.构成重载的条件：

方法名称相同，参数列表不同。参数列表可以在以下方面不同：

1.参数类型不同。
2.参数数量不同。
3.参数类型的排列顺序不同。

```java
void show(int num) {}
void show(String str) {}
void show(int a, int b) {}
void show(int num, String str) {}
void show(String str, int num) {}
```

2.不能构成重载的情况：

只有返回值类型、参数名称、访问修饰符或 `static` 不同，不能构成重载。

```java
int add(int a, int b) {
    return a + b;
}

// 编译错误：只有返回值类型不同
// double add(int a, int b) {
//     return a + b;
// }
```

调用方法时可以不接收返回值，因此编译器不能只根据返回值判断应该调用哪个方法。

3.构造方法也可以重载：

```java
class Student {
    Student() {}

    Student(String name) {}

    Student(String name, int age) {}
}
```

这样创建对象时可以使用不同的参数：

```java
Student a = new Student();
Student b = new Student("小明");
Student c = new Student("小明", 18);
```

4.自动类型转换和重载：

没有完全匹配的方法时，Java 可能通过自动类型转换选择可以调用的方法。

```java
void show(long num) {}

show(10); // int 可以自动转换为 long
```

如果多个重载方法都可以匹配，并且编译器无法判断哪一个更合适，就会产生调用歧义并编译报错。

```java
void show(String str) {}
void show(Integer num) {}

// show(null); // 编译错误：无法确定调用哪个方法
```

5.重载和重写的区别：

- 重载（Overload）：同名方法的参数列表不同，通常发生在同一个类中。
- 重写（Override）：子类重新实现父类中已有的方法，学习继承时再详细了解。

注意：重载的英文是 `overload`，示例类命名为 `MethodOverload`。`reload` 表示重新加载。

## 8.基本数据类型的自动转换：

将取值范围较小的数值类型转换为取值范围较大的类型时，Java 可以自动完成转换，也叫自动类型提升或扩大转换。

```java
byte a = 12;

print1(a); // byte 自动转换为 int
print2(a); // byte 自动转换为 double
```

```java
public static void print1(int num) {
    System.out.println(num);
}

public static void print2(double num) {
    System.out.println(num);
}
```

1.数值类型的自动转换顺序：

```text
byte -> short -> int -> long -> float -> double
               ^
char -----------|
```

`byte`、`short` 和 `char` 都可以自动转换为 `int`，再继续转换为更大的数值类型。

注意：`byte`、`short` 和 `char` 之间不能随意自动转换。例如，`byte` 不能自动转换为 `char`，`char` 也不能自动转换为 `short`。

2.大类型转换为小类型：

取值范围较大的类型不能自动转换为较小的类型，需要强制类型转换。

```java
int num = 130;
byte result = (byte) num;

System.out.println(result); // -126，超出 byte 范围后发生溢出
```

强制类型转换可能造成数据丢失、数值溢出或小数部分丢失。

3.整数常量的特殊情况：

如果整数常量的值在目标类型的范围内，Java 允许直接赋值。

```java
byte a = 12;
short b = 100;
char c = 65;
```

但是变量即使保存相同的数值，也不能直接缩小类型：

```java
int num = 12;
// byte a = num; // 编译错误
byte a = (byte) num;
```

4.表达式中的类型提升：

`byte`、`short` 和 `char` 参与算术运算时，会先自动提升为 `int`。

```java
byte a = 10;
byte b = 20;

// byte sum = a + b; // 编译错误，a + b 的结果是 int
int sum = a + b;
```

多个不同类型的数据进行运算时，结果通常会提升为其中范围较大的类型：

```java
int a = 10;
double b = 2.5;
double result = a + b; // int 自动提升为 double
```

5.扩大转换也可能损失精度：

整数转换为浮点数属于自动扩大转换，但数值较大时仍可能损失精度。

```java
long num = 123456789123456789L;
float result = num;

System.out.println(result); // 可以自动转换，但可能不再精确
```

6.`boolean` 不能参与数值类型转换：

```java
boolean flag = true;

// int num = flag;       // 编译错误
// boolean result = 1;   // 编译错误
```

Java 中的 `boolean` 只能取 `true` 或 `false`，不能和任何数值类型相互转换。

## 9.Scanner 键盘输入：

`Scanner` 是 Java 提供的输入工具类，可以读取并解析键盘输入。

1.`MyScanner` 代码解释：

```java
package com.ranan.scanner;

import java.util.Scanner;
```

`Scanner` 位于 `java.util` 包中，使用前需要通过 `import` 导入。

```java
Scanner sc = new Scanner(System.in);
```

`System.in` 表示标准输入，默认来自键盘。`new Scanner(System.in)` 创建一个用于读取键盘输入的 `Scanner` 对象。

```java
System.out.println("请输入用户名");
String username = sc.next();

System.out.println("请输入年龄");
int age = sc.nextInt();
```

`next()` 读取一个字符串，`nextInt()` 读取并解析一个整数。程序执行到输入语句时会暂停，等待用户输入。

```java
System.out.println(username + ' ' + age);
```

这里先将 `username` 和空格字符拼接为字符串，再拼接 `age`，最终输出用户名和年龄。

2.常用输入方法：

```java
String word = sc.next();       // 读取一个单词
String line = sc.nextLine();   // 读取一整行
int num = sc.nextInt();        // 读取 int
long bigNum = sc.nextLong();   // 读取 long
double value = sc.nextDouble();// 读取 double
boolean flag = sc.nextBoolean();// 读取 boolean
```

`Scanner` 默认使用空白字符作为分隔符，包括空格、换行和制表符。

3.`next()` 和 `nextLine()` 的区别：

- `next()`：读取下一个内容，遇到空白字符停止，不能读取带空格的完整文本。
- `nextLine()`：读取当前行剩余的全部内容，遇到换行符停止。

```java
// 输入：Zhang San
String a = sc.next();     // 得到 "Zhang"
String b = sc.nextLine(); // 得到 " San"
```

需要读取姓名、地址等可能包含空格的内容时，一般使用 `nextLine()`。

4.数字输入后读取整行的问题：

`nextInt()` 等方法只读取数字，不会读取数字后面的换行符。紧接着调用 `nextLine()` 时，它会读取这个残留的换行符，因此得到空字符串。

```java
int age = sc.nextInt();
sc.nextLine(); // 消耗数字后面残留的换行符

String address = sc.nextLine();
```

也可以统一使用 `nextLine()` 读取字符串，再手动转换：

```java
int age = Integer.parseInt(sc.nextLine());
double score = Double.parseDouble(sc.nextLine());
```

5.输入类型检查：

如果 `nextInt()` 读取到不能转换为整数的内容，会抛出 `InputMismatchException` 异常。可以先使用 `hasNextInt()` 判断：

```java
if (sc.hasNextInt()) {
    int age = sc.nextInt();
    System.out.println(age);
} else {
    System.out.println("输入的不是整数");
    sc.next(); // 取走错误输入，避免一直重复判断
}
```

常见的判断方法还有：

```java
sc.hasNext();        // 是否还有下一个内容
sc.hasNextLine();    // 是否还有下一行
sc.hasNextDouble();  // 下一个内容能否解析为 double
```

6.读取单个字符：

`Scanner` 没有 `nextChar()` 方法，可以先读取字符串，再取得第一个字符：

```java
char letter = sc.next().charAt(0);
```

`next()` 会跳过空白并等待下一个非空内容。如果使用 `nextLine()` 读取字符，用户可能直接输入空行，此时应先进行非空检查：

```java
String input = sc.nextLine();
if (!input.isEmpty()) {
    char letter = input.charAt(0);
}
```

7.关闭 Scanner：

使用结束后可以关闭 `Scanner`：

```java
sc.close();
```

关闭基于 `System.in` 创建的 `Scanner` 时，也会关闭标准输入，之后不能再从键盘读取内容。因此一个程序通常只创建一个键盘输入用的 `Scanner`，并在所有输入结束后再关闭。

也可以使用 `try-with-resources` 自动关闭：

```java
try (Scanner sc = new Scanner(System.in)) {
    String username = sc.nextLine();
    System.out.println(username);
}
```

注意：命令行参数 `String[] args` 是程序启动时传入的数据；`Scanner(System.in)` 是程序运行过程中由用户输入的数据，两者不是同一种输入方式。

## 10.异或运算符 ^：

`^` 表示异或（XOR）运算。它并不是 Java 独有的运算符，C++ 中也有相同用法。

1.整数的按位异或：

对两个整数的每一位二进制数字进行比较：

- 两位相同，结果为 `0`。
- 两位不同，结果为 `1`。

```text
5 = 0101
3 = 0011
---------
    0110 = 6
```

```java
int result = 5 ^ 3;
System.out.println(result); // 6
```

常见规律：

```java
int a = 5;
int b = 3;

int unchanged = a ^ 0;               // 结果仍为 a
int zero = a ^ a;                    // 结果为 0
boolean same = (a ^ b) == (b ^ a);   // 满足交换律
```

还可以使用异或赋值运算符：

```java
int num = 5;
num ^= 3; // 等价于 num = num ^ 3
```

2.`boolean` 的逻辑异或：

Java 允许对两个 `boolean` 值使用 `^`。两个值不同时结果为 `true`，相同时结果为 `false`。

| a     | b     | a ^ b |
| ----- | ----- | ----- |
| false | false | false |
| false | true  | true  |
| true  | false | true  |
| true  | true  | false |

```java
boolean result1 = true ^ false; // true
boolean result2 = true ^ true;  // false
```

`^` 的两边都会执行，不具有 `&&` 和 `||` 的短路效果。

3.注意事项：

`^` 不是乘方运算符：

```java
int result = 2 ^ 3;       // 异或，结果为 1
double power = Math.pow(2, 3); // 乘方，结果为 8.0
```

进行多个位运算或与其他运算符混合使用时，建议添加括号明确运算顺序。

## 11.BMI 和 BMR 健康计算器练习：

这个练习综合使用了 `Scanner` 输入、循环校验、方法拆分、`double` 计算和格式化输出。

1.BMI 和 BMR 的计算：

BMI（身体质量指数）用于根据身高和体重粗略评估体重状况：

```text
BMI = 体重（kg）/ 身高（m）²
```

如果输入的身高单位是厘米，需要先转换为米：

```java
public static double getBMI(double height, double weight) {
    return weight / Math.pow(height / 100, 2);
}
```

BMR（基础代谢率）表示人在基础静息状态下一天大约消耗的能量。练习中使用 Mifflin-St Jeor 估算公式，体重单位为 `kg`，身高单位为 `cm`，年龄单位为岁：

```text
男性 BMR = 10 × 体重 + 6.25 × 身高 - 5 × 年龄 + 5
女性 BMR = 10 × 体重 + 6.25 × 身高 - 5 × 年龄 - 161
```

```java
public static double getBMR(String gender, int age,
                            double height, double weight) {
    if ("男".equals(gender)) {
        return 10 * weight + 6.25 * height - 5 * age + 5;
    } else {
        return 10 * weight + 6.25 * height - 5 * age - 161;
    }
}
```

BMI 和 BMR 都是估算结果，不能代替医学检查或专业建议。

2.整个程序只创建一个 `Scanner`：

不要在每个读取方法中分别创建 `new Scanner(System.in)`。它们读取的是同一个标准输入，并且任何一个 `Scanner` 被关闭时，`System.in` 也会被关闭，后续输入就不能继续使用。

推荐在 `main()` 中创建一个 `Scanner`，再作为参数传给各个输入方法。所有输入和输出结束后，再统一关闭。

```java
public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);

    int age = getAge(sc);
    double height = getHeight(sc);

    System.out.println(age);
    System.out.println(height);
    sc.close();
}
```

```java
public static int getAge(Scanner sc) {
    return sc.nextInt();
}
```

这样 `main()` 负责创建和关闭资源，其他方法只负责完成各自的输入任务。

3.读取 `double` 并校验输入：

检查和读取的类型必须一致。`hasNextDouble()` 判断下一个输入能否转换为 `double`，对应的读取方法必须是 `nextDouble()`。

```java
public static double getHeight(Scanner sc) {
    while (true) {
        System.out.println("请输入身高（cm）：");
        if (sc.hasNextDouble()) {
            double height = sc.nextDouble();
            if (height > 0) {
                return height;
            }
        } else {
            sc.next(); // 取走错误输入，避免下一轮重复读取
        }
        System.out.println("输入不合法！");
    }
}
```

如果已经使用 `hasNextDouble()`，却调用 `nextInt()`，输入 `170.5` 时会抛出 `InputMismatchException`。体重的输入逻辑也是同样的道理。

4.字符串内容比较：

`==` 比较两个引用是否指向同一个对象，不适合判断字符串文字是否相同。比较内容时使用 `equals()`。

```java
String gender = "男";

if ("男".equals(gender)) {
    System.out.println("使用男性 BMR 公式");
}
```

将固定字符串写在前面，即使 `gender` 为 `null` 也不会抛出 `NullPointerException`。

5.格式化输出：

`System.out.printf()` 可以按指定格式输出数据，和 C++ 的 `printf` 用法相似，但不会自动换行。

```java
double bmi = 22.857142;
double bmr = 1673.75;

System.out.printf("BMI：%.2f kg/m^2%n", bmi);
System.out.printf("BMR：%.2f kcal/day%n", bmr);
```

输出结果：

```text
BMI：22.86 kg/m^2
BMR：1673.75 kcal/day
```

常用格式：

| 格式 | 含义 |
| --- | --- |
| `%d` | 整数 |
| `%f` | 小数 |
| `%.2f` | 按四舍五入显示两位小数 |
| `%s` | 字符串 |
| `%c` | 单个字符 |
| `%b` | 布尔值 |
| `%n` | 换行 |

如果需要先生成字符串而不立即输出，可以使用 `String.format()`：

```java
String result = String.format("BMI：%.2f", bmi);
```

6.控制输出宽度和对齐：

在 `%` 后、类型字母前添加数字，可以指定字段的最小输出宽度。默认右对齐；添加 `-` 表示左对齐。

```java
System.out.printf("|%10s|%8.2f|%n", "BMI", 22.63);
```

输出结果：

```text
|       BMI|   22.63|
```

常用格式：

| 格式 | 含义 |
| --- | --- |
| `%10s` | 字符串最少占 10 个位置，右对齐 |
| `%-10s` | 字符串最少占 10 个位置，左对齐 |
| `%8d` | 整数最少占 8 个位置，右对齐 |
| `%8.2f` | 小数最少占 8 个位置，保留两位小数 |
| `%-8.2f` | 小数最少占 8 个位置，左对齐并保留两位小数 |

可以用它让 BMI 和 BMR 的输出更整齐：

```java
System.out.printf("%-10s %8.2f%n", "BMI", bmi);
System.out.printf("%-10s %8.2f%n", "BMR", bmr);
```

宽度不足时，内容不会被截断，而是会完整输出。中文字符在部分终端的视觉宽度可能比英文字符更宽，因此表格看起来不一定完全对齐。

7.命名规范：

类名使用大驼峰，例如 `Practice`；方法名、变量名使用小驼峰，例如 `getGender`、`userHeight`、`weight`。

```java
double Height; // 不推荐，变量名不应以大写字母开头
double height; // 推荐
```

`gender` 表示性别，比拼写错误的 `sextual` 更清楚、合适。

8.`next()` 和姓名输入：

`next()` 遇到空格就停止读取，适合读取不含空格的姓名或用户名。若要支持带空格的完整姓名，需要使用 `nextLine()`。当它跟在 `nextInt()`、`nextDouble()` 后面时，要先用一次 `nextLine()` 消耗残留的换行符。
